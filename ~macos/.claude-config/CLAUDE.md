# User memory

Personal, cross-project preferences for Claude Code. Applies everywhere I work.
Project-specific rules belong in that repo's own `CLAUDE.md`, not here.

## Environment

- macOS, zsh, terminal-first.

## Communication

- Be concise and direct. Lead with the answer, then a short reason if needed.
- Skip preamble and filler. Don't restate my request back to me.
- If you're unsure, say so instead of guessing.

## Coding

- Match the surrounding code's style, naming, and conventions.
- No comments unless the code is genuinely non-obvious.
- Prefer standard, widely-installed tools over adding new dependencies.
